# Scrum-lite case study

A short sprint organized the development into testable tasks without suggesting that the example was deployed at a real organization.

**Sprint goal:** Deliver an independently reproducible synthetic demonstration of demand-to-coverage analysis and clear limitations.

| Task | Acceptance criteria | Status |
|---|---|---|
| Prepare example inputs | Synthetic generator uses a fixed random seed | Done |
| Validate inputs | Schema and basic type checks | Done |
| Calculate workload | Report quality-approved ratios only | Done |
| Visualize results | Heatmap generated from synthetic input | Done |
| Publish safely | No confidential or identifying material | Requires history review |
| Power BI prototype | Works entirely with synthetic data | Backlog |

**Definition of done:** Code runs from a clean environment, assumptions are documented, charts are labeled as synthetic, and publication screening is complete. No managerial approval or business outcome is implied.
