# Publication checklist

- [ ] Every published dataset is clearly labeled **synthetic** and generated independently.
- [ ] No employer/customer/vendor names, proprietary system names, specific locations, real business dates, exact sales figures, employee details, or private screenshots occur in any tracked file.
- [ ] No proprietary CSVs or private notebooks occur in Git history, not just in the current working tree.
- [ ] The README and diagrams do not imply measured staffing improvements or financial impact.
- [ ] Project technologies are described accurately; planned tools are not presented as completed.
- [ ] Review `git status`, `git diff --cached --name-only`, and `git diff --cached` before committing.
- [ ] If a repository has previously contained identifying or confidential information, changing the latest files **does not remove earlier commits**. Review the full history before using it publicly; consider a new repository with a clean history.
